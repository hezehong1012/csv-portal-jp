01基礎

CSVとは（定義と3つのルール）

CSVは Comma-Separated Values の略で、日本語では「カンマ区切り値」と呼ばれます。規格として広く参照されるのは RFC 4180（IETF 発行の仕様書） で、ファイル形式・引用符・改行の扱いが定義されています。覚えておくべきルールは次の3つだけです。

  1. 1行＝1件のデータ1行目は項目名（ヘッダー）にするのが一般的です。2行目以降が実データになります。
  2. 項目はカンマで区切るカンマの位置で列が決まります。列の順番に意味があるため、途中で入れ替えると別物になります。
  3. カンマ・改行・ダブルクォートを含む値は「"」で囲む値の中のダブルクォートは二重にして "" と書きます。ここを守らないと列がずれます。

Excelの表示と、CSVの中身は違う

同じデータでも、Excelで見たときとテキストとしての中身は別物です。

Excelでの表示CSVファイルの中身
氏名 / 部署 / 備考氏名,部署,備考
佐藤 / 営業 / 東京佐藤,営業,東京
鈴木 / 開発 / 大阪, 出張可鈴木,開発,"大阪, 出張可"

3行目の備考にカンマが入っているため、値全体がダブルクォートで囲まれています。この引用符がないと列が1つずつずれ、以降の行がすべて崩れます。CSVのトラブルの多くはここに起因します。

区切り文字はカンマとは限らない

ヨーロッパ圏では小数点にカンマを使うため、区切り文字をセミコロンにしたCSVが一般的です。読み込む側では区切り文字を固定せず、判定させるのが安全です。

05比較

CSVとExcelの違い

結論から言えば、Excelはアプリケーション、CSVはデータの入れ物です。

観点CSVExcel（.xlsx）
実体ただのテキスト書式・数式・グラフを保持する複合ファイル
見た目保てない（色・太字・列幅は消える）保てる
数式保存されない（計算結果の値のみ）保存される
シート数1ファイル1シート複数シート可
行数の上限なし（ソフト側の制限のみ）1,048,576行 / 16,384列
相互運用性ほぼすべてのソフトが読めるExcel系ソフトが必要
向く用途システム間のデータ連携人に見せる資料・分析

実務では「受け渡しはCSV、加工と提示はExcel」という役割分担が基本です。

「CSV経営」はファイル形式とは無関係

「csv 経営」「csr csv 違い」の検索で当たるCreating Shared Value（共通価値の創造）は、マイケル・ポーターが提唱した経営概念で、社会課題の解決と経済価値の創出を両立させる考え方です（FSG / Shared Value イニシアティブ（公式））。ファイル形式のCSVとは綴りが同じだけの別物です。

08FAQ

よくある質問

Q.CSVとは何の略ですか？

Comma-Separated Values（カンマ区切り値）の略です。データをカンマで区切って並べたテキストファイルを指し、拡張子は .csv です。

Q.CSVとExcelは何が違いますか？

Excelは表計算ソフト、CSVはデータの入れ物（テキスト形式）です。CSVは書式・数式・複数シートを保持できませんが、軽量でどのソフトからも読めます。

Q.CSVをExcelで開くと文字化けするのはなぜですか？

保存時の文字コードとExcelが想定する文字コードが違うためです。「データ」→「テキスト/CSVから」で文字コードを指定して開けば解消します。詳しくは文字化けの専用ページへ。

Q.UTF-8とShift-JISはどちらで保存すべきですか？

Webサービスやクラウドツールとの連携はUTF-8、国内の基幹システム・会計ソフト・官公庁提出はShift-JISが基本です。相手側の仕様を確認してください。

Q.先頭の0が消えてしまうのはなぜですか？

Excelが数値と解釈するためです。インポート時に該当列を「テキスト」に指定するのが最も確実です。詳しくは変換の専用ページへ。

Q.CSVは複数シートにできますか？

できません。CSVは1ファイル＝1シートです。複数シートのブックをCSV保存すると、アクティブなシートだけが書き出されます。

Q.CSVとTSVの違いは何ですか？

区切り文字が違うだけです。CSVはカンマ、TSVはタブで区切ります。

Q.「CSV経営」のCSVは同じ意味ですか？

別物です。Creating Shared Value（共通価値の創造）の略で、社会課題の解決と経済価値の創出を両立させる経営手法を指します。

Q.CSVファイルのアイコンがExcelになってしまう

Windowsが.csvをExcelに関連付けているためです。実害はありませんが、ダブルクリックで開くと文字化けの原因になります。右クリック→「プログラムから開く」→「メモ帳」を選びましょう。

Q.数万行のCSVがExcelで開けません

Excelの上限は1,048,576行です。超えると切り捨てられることがあります。Power Queryで必要列だけ読むか、Python＋pandasで集計してください。

Q.CSVをPDFに変換できますか？

できます。Excelで開いてレイアウトを整え、「エクスポート」→「PDF/XPSの作成」を選びます。

Q.CSVの区切り文字をカンマ以外にできますか？

できます。ヨーロッパではセミコロン、日本ではタブ（TSV）が使われることがあります。
