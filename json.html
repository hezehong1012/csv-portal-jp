CSV ⇄ JSON 変換ツール

CSVをJSONへ、JSONをCSVへ。ファイルを選ぶか貼り付けるだけで、ブラウザ内でその場で変換します。型変換・ネスト・JSON Linesまで細かく指定できます。

使い方（3ステップ）

  1. CSVを読み込むテキストを貼り付けるか、ファイルを選択します。1行目がヘッダーかどうか、区切り文字（カンマ／セミコロン／タブ）を指定してください。
  2. オプションを選ぶ出力形式（オブジェクト配列・配列の配列・JSON Lines）、インデント、数値・真偽値の型変換、ドット記法をネストにするかを選びます。
  3. 変換して保存「変換する」を押すと結果が表示されます。コピーするか、.json / .csv としてダウンロードしてください。

このツールの特徴

双方向の変換

CSV→JSON と JSON→CSV の両方に対応。タブで切り替えるだけです。

型を壊さない

「001」のような先頭ゼロは文字列のまま、「42」は数値に。意図しない型変化を避けられます。

ネストと平坦化

address.city のような列名を入れ子のJSONに。逆にネストしたJSONはドット記法で平坦化してCSVにできます。

JSON Lines 対応

1行1レコードの NDJSON / JSONL 形式でも出力できます。ログ取り込みやBigQuery向けです。

表記ゆれの吸収

区切り文字は自動判定。セミコロン区切りの欧州CSVやタブ区切りもそのまま読めます。

完全クライアント処理

変換はすべてブラウザ内で完結し、ファイルはサーバーに送信されません。

よくある質問

CSVをJSONに変換すると、数値が文字列になってしまいます。
「数値・真偽値を型変換」をONにしてください。ただし「001」のように先頭が0の値は、意図的に文字列として保持します。
セミコロン区切りのCSVでも変換できますか？
はい。区切り文字は自動判定のほか、カンマ／セミコロン／タブ／パイプから明示的に選べます。
ネストしたJSONはCSVにできますか？
できます。オブジェクトはドット記法（address.city）で平坦化し、配列はJSON文字列として1セルに格納します。
大きなファイルでも大丈夫ですか？
ブラウザのメモリの範囲内で動作します。数万行程度までを目安にしてください。
データは送信されますか？
いいえ。変換はすべてブラウザ内で完結し、サーバーには一切送信されません。
