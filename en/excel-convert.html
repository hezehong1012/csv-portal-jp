CSV ⇄ Excel: the complete conversion guide

Moving data between CSV and Excel is the single most-searched CSV topic there is. Opening a CSV and saving one are two different jobs, with two different sets of traps. This guide covers both directions, step by step, with sources from Microsoft's official documentation.

Updated October 30, 2026Reading time about 11 minutesSources official documentation only
THE SHORT ANSWER

To get a CSV into Excel, use Data → From Text/CSV (never double-click the file). To turn Excel into a CSV, use Save As → CSV UTF-8. In both directions the column type is what matters: if you do not set code columns to Text, the leading zeros are gone.

02Import

Convert CSV to Excel (import)

Double-clicking is the one thing to avoid. Excel looks at the contents and guesses each column's type, so leading zeros vanish from product codes and 13-digit numbers turn into scientific notation such as 1.23457E+12. The correct procedure is below (it follows Microsoft's official import steps).

  1. Launch Excel and open a blank workbookDo not double-click the CSV. Start Excel first.
  2. Choose Data → From Text/CSVA file picker opens.
  3. Select the CSV fileA preview appears, with the delimiter and encoding detected automatically.
  4. Check the encoding under File OriginIf the preview looks garbled, switch to 65001: UTF-8 or 932: Shift-JIS.
  5. Turn off Data Type Detection, then set the columns you care about to TextProduct code and phone number columns must be Text. This is the heart of the leading-zero fix.
  6. Click Load, then save as .xlsx if you need toFrom that point on you can edit without damaging the source data.
If you import the same CSV over and over

Load it with Data → From File and keep the import as a Power Query query. Next time, one click on Refresh brings the data in with the same cleaning rules applied. Column types are pinned as well, so leading zeros cannot go missing again.

03Save

Convert Excel to CSV (save)

  1. Activate the sheet you want to exportOnly one sheet is saved.
  2. Choose File → Save As
  3. Pick the file typeUse "CSV UTF-8 (Comma delimited)" for external systems, and "CSV (Comma delimited)" for legacy domestic business software.
  4. Convert the encoding afterwards if you need toOpen the file in Notepad, choose Save As, and set Encoding to ANSI to end up with Shift-JIS.
What "CSV export" usually means

Most searches for "csv export" are about a system or a program writing out a CSV file. For exporting from Excel, use the steps above; for exporting from code, see the "Writing CSV" section of the reading and writing guide.

Which format should you save in?

FormatEncodingBest forWatch out for
CSV UTF-8 (Comma delimited)UTF-8 (with BOM)Web services and external toolsMay still break in older Excel builds or some business systems

06Scale

Converting large files

Excel's hard limit is 1,048,576 rows by 16,384 columns. A CSV bigger than that risks being truncated. Switch to one of the following instead.

  • Power Query — pull only the columns and rows you need into Excel (workable up to a few hundred thousand rows)
  • Python + pandas — read in chunks with chunksize (code examples here)
  • A lightweight database such as DuckDB — query millions of rows directly with SQL

07FAQ

Frequently asked questions

Q.Do formats survive a CSV-to-Excel conversion?

No. CSV is plain text, so colours, bold text and column widths are not carried across. If the appearance matters, work in .xlsx instead.

Q.Is "csv to excel" the same thing?

Yes. It means either turning a CSV into the Excel format (.xlsx) or simply opening it in Excel. The steps are in section 02 of this page.

Q.How do I save Excel as CSV without garbling the text?

Save as "CSV UTF-8 (Comma delimited)". If the recipient runs a legacy system, choose Shift-JIS instead. For the full procedure see the dedicated encoding guide.

Q.Can I convert several sheets to CSV at once?

Not with the built-in features — it is one sheet at a time. The standard workaround is a VBA or macro loop that saves each sheet in turn.

Q.How do I check the row count after converting?

In Excel press Ctrl+End to jump to the last cell, in Power Query read the row count shown in the preview, and in code just count the rows.
