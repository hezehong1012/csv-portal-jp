What Is a CSV File? A Complete Guide to Creating, Converting, and Fixing CSVs

CSV is still one of the most widely exchanged data formats there is. Yet the same handful of problems keeps coming back — the file opens as garbage, the leading zeros vanish. This guide gives you the whole picture on a single page and hands the deep dives to dedicated pages: five pages in total.

Updated October 30, 2026Reading time About 10 minSources Official documentation only
In short

A CSV (comma-separated values) file is a plain text file that lays out data in rows separated by commas. One line is one record — a structure so simple that Excel, Google Sheets, databases, and almost every other piece of software can read and write it. The extension is .csv.

01Basics

What Is a CSV File? Definition and Three Rules

CSV stands for comma-separated values. The specification people cite most often is RFC 4180, published by the IETF, which defines the file format along with how quotes and line breaks are handled. You only need to remember three rules.

  1. One line equals one recordThe first line conventionally holds the field names (the header), and every line after it is actual data.
  2. Fields are separated by commasEach comma marks a column boundary. Column order carries meaning, so shuffle the fields and you have a different dataset.
  3. Quote any value containing a comma, a line break, or a double quoteA double quote inside a value is escaped by doubling it: "". Break this rule and your columns shift.

What Excel shows is not what the file contains

The same data looks like one thing in Excel and quite another as plain text.

As shown in ExcelWhat the CSV file actually contains
Name / Department / Notesname,department,notes
Sato / Sales / TokyoSato,Sales,Tokyo
Suzuki / Engineering / Osaka, available for travelSuzuki,Engineering,"Osaka, available for travel"

The notes field on the third row contains a comma, so the whole value is wrapped in double quotes. Without those quotes every column shifts by one and every following row collapses. Most CSV trouble traces back to this.

The delimiter isn't always a comma

Much of Europe uses a comma as the decimal separator, so semicolon-delimited CSVs are the norm there. When you read a file, let the parser detect the delimiter instead of hard-coding it.

03Converting

Converting Between CSV and Excel

Opening and saving are two different operations with two different sets of pitfalls. Avoid double-clicking the file and go through Data → From Text/CSV instead. Follow Microsoft's official import steps and you avoid both the disappearing leading zero and scientific notation such as 1.23457E+17.

05Comparison

CSV vs. Excel: What's the Difference?

The short answer: Excel is an application, CSV is a container for data.

AspectCSVExcel (.xlsx)
What it really isPlain textA compound file that stores formatting, formulas, and charts
AppearanceNot preserved (colors, bold, column widths all disappear)Preserved
FormulasNot stored (only the calculated result)Stored
WorksheetsOne sheet per fileMultiple sheets allowed
Row limitNone (only whatever limit the software imposes)1,048,576 rows / 16,384 columns
InteroperabilityReadable by virtually any applicationRequires Excel-compatible software
Best suited toMoving data between systemsReports and analysis for people to read

In practice the division of labour is simple: CSV for hand-off, Excel for shaping and presenting.

"CSV" also stands for Creating Shared Value

Searches for "csv business" or "csv vs csr" land on Creating Shared Value, the management concept Michael Porter introduced to describe companies solving social problems while creating economic value (FSG / Shared Value Initiative, official site). It shares a spelling with the file format and nothing else.

08FAQ

Frequently Asked Questions

Q.What does CSV stand for?

Comma-separated values. It describes a text file in which data is arranged in rows separated by commas, and the extension is .csv.

Q.How is a CSV different from an Excel file?

Excel is spreadsheet software; a CSV is a container for data in plain text. A CSV cannot hold formatting, formulas, or multiple sheets, but it is lightweight and every application can read it.

Q.Why does a CSV turn into garbage when I open it in Excel?

The encoding the file was saved in does not match the encoding Excel assumes. Open it through Data → From Text/CSV and specify the encoding — that fixes it. For the full walkthrough, see the dedicated page on garbled text.

Q.Should I save as UTF-8 or Shift-JIS?

UTF-8 for web services and cloud tools; Shift-JIS for domestic core systems, accounting software, and government submissions. Confirm what the receiving side expects.

Q.Why do leading zeros disappear?

Excel interprets the value as a number. The most reliable fix is to mark that column as Text at import time. See the conversion page.

Q.Can a CSV have multiple sheets?

No. One CSV file equals one sheet. Saving a multi-sheet workbook as CSV exports only the active sheet.

Q.What is the difference between CSV and TSV?

Only the delimiter. CSV separates fields with commas; TSV uses tabs.

Q.Is the CSV in "CSV business" the same thing?

No. There it stands for Creating Shared Value, a management approach that pursues social progress and economic value creation at the same time.

Q.My CSV files show an Excel icon — is something wrong?

No. Windows associates .csv with Excel by default. Nothing is broken, but double-clicking is exactly what causes garbled text. Right-click → Open with → Notepad.

Q.A CSV with tens of thousands of rows won't open in Excel

Excel caps out at 1,048,576 rows, and anything beyond that can be truncated. Load just the columns you need with Power Query, or aggregate the file with Python and pandas.

Q.Can I convert a CSV to PDF?

Yes. Open it in Excel, tidy up the layout, then choose Export → Create PDF/XPS.

Q.Can I use a delimiter other than a comma?

Yes. Semicolons are the norm in much of Europe, and tabs (TSV) are sometimes used instead.
