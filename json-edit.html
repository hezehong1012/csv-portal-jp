JSON エディタ

ツリー表示で構造をたどり、整形・圧縮・エスケープ・Unicode デコードをその場で。タブを切り替えるだけで JSON→CSV 変換と 2 つの JSON の差分比較も同じページでできます。すべてブラウザ内で処理され、データは送信されません。

まだ変換していません

使い方

  1. JSON を貼り付けるか、.json ファイルを選択します。
  2. 「解析してツリー表示」で構造をたどり、整形・圧縮・エスケープなどの操作を押します。
  3. 「JSON → CSV」タブで変換、「JSON Diff」タブで 2 つの JSON の違いを確認できます。

このツールでできないこと

ツリー表示と Diff は解析結果の確認用です。100 万文字を超えるような巨大な JSON では、ツリーのノード数を上限までに制して表示します。JSON→CSV はオブジェクトの配列（または JSON Lines）を想定しており、配列の中に配列が直接入るデータは 1 行ずつ JSON 文字列として格納します。

よくある質問

整形と圧縮の違いは何ですか？
整形はインデントと改行を付けて読みやすくする処理、圧縮は余白をすべて取り除いて 1 行にする処理です。どちらも JSON としての中身は変わりません。
ネストした JSON を CSV にするとどうなりますか？
「ネストをドット記法で平坦化」がオンの場合、address.city のような列名に展開されます。配列は JSON 文字列として 1 セルに格納します。
JSON Lines (.jsonl) はそのまま使えますか？
はい。1 行 1 レコードの JSON Lines は自動判定して、配列として読み込みます。
Diff はどこまで細かく分かりますか？
ドット記法のパス単位で、追加・削除・変更を判定します。たとえば user.name が変わっていれば「user.name: 変更前 → 変更後」と表示します。
データは送信されますか？
いいえ。解析・変換・比較のすべてがブラウザ内で完結し、サーバーには一切送信されません。
