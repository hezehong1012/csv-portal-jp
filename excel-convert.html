CSV⇔Excel 変換のすべて

CSVとExcelの変換は、日本で最も検索されるCSV関連テーマです（月間合計2万件以上）。「開く」と「保存する」は落とし穴が別物です。両方向の正しい手順を、Microsoft公式ドキュメントの出典つきで解説します。

更新日 2026年10月30日読了時間 約11分出典 公式ドキュメントのみ
結論

CSV→Excelは「データ」→「テキスト/CSVから」で読み込み（ダブルクリック禁止）、Excel→CSVは「名前を付けて保存」→「CSV UTF-8」。どちらも列の型の扱いが重要で、商品コード系の列は「テキスト」指定にしないと先頭の0が消えます。

TOOL手順を踏まずに、その場で変換する手順ページで解説している作業を、そのままブラウザで実行できます。

02読み込み

CSVをExcelに変換する（読み込み）

ダブルクリックで開くのは避けたほうが安全です。Excelは中身を見て自動で型を推測するため、コードの先頭0が消えたり、13桁の数字が 1.23457E+12 のような指数表記になったりします。以下が正しい手順です（Microsoft 公式インポート手順に準拠）。

  1. Excelを起動し、空のブックを開くCSVをダブルクリックせず、先にExcelを立ち上げます。
  2. 「データ」タブ→「テキスト/CSVから」を選ぶファイル選択ダイアログが開きます。
  3. 対象のCSVを選ぶプレビュー画面が表示され、区切り文字と文字コードが自動判定されます。
  4. 「元のファイル」で文字コードを確認する日本語が崩れていれば「65001: UTF-8」か「932: Shift-JIS」に切り替えます。
  5. 「データ型を検出」をオフにし、必要な列を「テキスト」にする商品コード・電話番号の列は必ずテキストに。ここが0落ち対策の核心です。
  6. 「読み込み」を押し、必要ならxlsxで保存する以後は加工しても元データが壊れません。
毎回同じCSVを取り込むなら

「データ」→「からファイル」で読み込みをPower Queryのクエリとして保存しておくと、次回から更新ボタンひとつで同じ整形ルールのまま取り込めます。列の型も固定されるため、0落ちが再発しません。

03保存

ExcelをCSVに変換する（保存）

  1. CSVにしたいシートをアクティブにする保存されるのは1シートだけです。
  2. 「ファイル」→「名前を付けて保存」
  3. 形式を選ぶ外部システムへは「CSV UTF-8（コンマ区切り）」、国内の古い業務システムへは「CSV（コンマ区切り）」。
  4. 保存後、必要なら文字コードを変換するメモ帳で開き直して「名前を付けて保存」→エンコードをANSIにするとShift-JISになります。
「CSV 出力」とは

「csv 出力」で検索される场景の多くは、システムやプログラムからCSVファイルを書き出すことを指します。Excelからの書き出しは上の手順、プログラムからの書き出しは読み書きの専用ページの「書き出し」の章を参照してください。

04選択

どちらの形式で保存すべきか

保存形式文字コード向いている場面注意点
CSV UTF-8（コンマ区切り）UTF-8（BOMあり）Webサービス・外部ツールとの連携古いExcelや一部の業務システムでは化けることがある
CSV（コンマ区切り）Shift-JIS（CP932）国内の基幹システム・会計ソフト・官公庁提出絵文字や一部の漢字は「?」になる
CSV（Macintosh）Shift-JIS・CR改行Mac版の古いソフト現在はほぼ不要。文字化けの温床

迷ったらまずUTF-8で渡し、相手側で化けたらShift-JISに切り替えるのが現代の基本線です。

0落ちや指数表記は表示の問題ではなくデータ自体が変わっています。上書き保存した後は復元できないため、必ず元のCSVから作り直してください。

06発展

大量データの変換

Excelの上限は1,048,576行・16,384列です。これを超えるCSVは切り捨てられる恐れがあります。次のいずれかに切り替えてください。

  • Power Query — 必要な列・行だけExcelに取り込む（数十万行まで実用的）
  • Python + pandas — chunksize で分割読み込み（コード例は専用ページ）
  • DuckDB などの軽量DB — 数百万行でもSQLで直接集計可能

07FAQ

よくある質問

Q.CSVをExcelに変換すると書式は消えますか？

消えます。CSVはテキストなので、色・太字・列幅は保持されません。見た目が必要ならxlsxで作業してください。

Q.csv to excel は同じ意味ですか？

はい。CSVをExcel形式（.xlsx）にする、またはExcelで開くことを指します。手順はこのページの02章です。

Q.ExcelをCSVにして文字化けさせないには？

「CSV UTF-8（コンマ区切り）」で保存します。相手側が古いシステムならShift-JISを選びます。詳しくは文字化けの専用ページへ。

Q.複数シートを一括でCSVにできますか？

標準機能では1シートずつです。VBAやマクロでループ保存するのが定番の回避策です。

Q.変換後の行数を確認するには？

ExcelならCtrl+Endで最終セルへ移動、Power Queryならプレビューの行数表示、プログラムなら行数カウントで確認できます。
